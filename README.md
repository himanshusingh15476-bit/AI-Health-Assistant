# 🏥 AI Health Assistant

AI Health Assistant is a Flask-based web application that uses Google Gemini AI to analyze patient symptoms and generate a medical report.

## Features

- AI Medical Report
- BMI Calculator
- Health Score
- Health Risk
- Download PDF
- Print Report
- Copy Report

## Technologies Used

- Python
- Flask
- Google Gemini AI
- HTML
- CSS
- JavaScript
- ReportLab

## Run the Project

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```

Open your browser:

```
http://127.0.0.1:5000
```
